# SQL Data Analysis Portfolio Project

## 📊 Project Overview
This repository contains a comprehensive **Retail Transaction Analysis** project built using **Oracle 10g**. The objective is to transform raw retail transactional records into actionable business insights using standard and advanced SQL queries.

## 🛠️ Technology Stack
* **Database Engine**: Oracle 10g
* **Query Development**: SQL Developer / SQL*Plus
* **Version Control**: Git & GitHub

## 📂 Repository Structure
* `data/` - Contains sample dataset insertion scripts.
* `scripts/` - Contains modular SQL queries:
  * `module_a_exploration.sql` - Data exploration & quality checks.
  * `module_b_sales_performance.sql` - Revenue totals, AOV, and category metrics.
  * `module_c_time_analysis.sql` - Monthly sales and trend breakdowns.
  * `module_d_customer_analysis.sql` - Customer spending and repeat buyers.
  * `module_e_product_analysis.sql` - Product and category performance.
  * `module_f_advanced_analytics.sql` - CTEs, window functions (`RANK`, `DENSE_RANK`), and running totals.
* `outputs/` - Screenshots and query result summaries.

## 📈 Key Analytical Modules & Insights
1. **Sales Performance**: Evaluated total revenue, units sold, and regional contributions.
2. **Time-Based Trends**: Tracked monthly performance shifts.
3. **Customer Insights**: Identified top-spending customers and transaction frequencies.
4. **Advanced Analytics**: Leveraged Oracle window functions to rank products by category and calculate running cumulative revenues.
